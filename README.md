# CS50 Quiz App 🧠

A simple and interactive quiz application built as my CS50 Final Project.

The quiz contains 10 questions about programming and computer science. 
Users can answer the questions, track their progress, and get their final result at the end of the quiz.

## Features ✨

- 10 multiple-choice questions
- CS50 and computer science related questions
- Countdown timer for each question
- Progress indicators
- Automatic answer checking
- Final score calculation
- Different result messages based on the score
- Different images for Perfect, Good, and Bad results
- Questions are loaded dynamically from a JSON file

## Technologies Used 💻

- HTML
- CSS
- JavaScript
- JSON
